# ColorSnatch Icons

This directory should contain the following icon files for the extension:

- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You need to create these icons manually and place them in this directory.

Suggested icon design: Use a colorful eyedropper or color picker tool as the main symbol.

You can use tools like:
- Adobe Illustrator
- Figma
- GIMP
- [Favicon.io](https://favicon.io/)

To generate the icons in the required sizes.
